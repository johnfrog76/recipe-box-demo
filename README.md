# RecipeBox

A small recipe app: keep recipes, scale them by servings, plan the week, shop from the list.

This repository is the **GitHub demo** Space of ToolKit. Its issues, milestones and labels are
sample data, seeded once so the toolkit's Issues, Board, Stats and Design tabs read something real.
Nothing here is real work, and none of it belongs to anybody.

- `design/` holds the notes a decision came from; `spec/` holds what was decided.
- `docs/` is how to run it.
